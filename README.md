# ETF 智能监测工具（单窗口看板）

监测 **红利 515180 / 银行 516310 / 煤炭 515220** 三只 ETF，一个浏览器页面看完全部指标。

## 云端看板（手机/电脑随时看，无需开电脑）

**看板网址：https://xhxie123-maker.github.io/etf-monitor/output/etf_dashboard.html**

- 由 GitHub Actions 每个工作日 15:35（北京时间）自动更新，更新后自动发布到该网址
- 手机、轻薄本打开网址即看全部指标
- 仓库 Actions 页可手动点「Run workflow」立即更新
- 估值分位历史随仓库持久化（`output/valuation_history.csv`），每日自动 +1 期

## 本地快速开始

- **自动运行**：已配置 Windows 计划任务「ETF每日监测」，每个工作日 15:30 收盘后自动更新看板
- **手动更新**：双击 `run_monitor.bat`，更新后自动打开浏览器
- **查看看板**：打开 `output\etf_dashboard.html`（双击即可，无需联网，ECharts 为本地文件）

## 看板内容

1. **创业板红利比**：创业板指(399006) ÷ 中证红利(000922)，近3年历史分位 + 风格轮动建议（<0.35 成长占优 / >0.60 红利占优）
2. **单只ETF卡片**：最新价、涨跌幅、PE/PE分位、股息率、RSI、MA20/MA60、偏离20日线、做T支撑/压力位
3. **买卖信号**：综合评分制（估值+RSI+布林+均线+偏离），输出 强烈分批买入 / 逢低分批买入 / 观望持有 / 逢高减仓
4. **定投建议**：按PE分位分档（双倍 / 正常 / 减半 / 暂停）
5. **价格走势图**：近250日收盘 + MA20/MA60 + 布林带
6. **估值分位走势图**：PE历史百分位（本地积累库）
7. **长期操作纪律**：基准仓位、再平衡规则、风险提示

## 文件说明

| 文件 | 作用 |
|------|------|
| `etf_monitor.py` | 主脚本：抓数据→算指标→生成看板 |
| `run_monitor.bat` | 手动更新并打开看板 |
| `libs\echarts.min.js` | 本地图表库（离线可用） |
| `output\etf_dashboard.html` | 看板成品（每日覆盖更新） |
| `output\valuation_history.csv` | 估值历史积累库（分位样本，每日追加） |
| `output\run_log.txt` | 运行日志 |

## 数据源与说明

- **行情**：东方财富（akshare 接口），前复权日线
- **估值**：中证指数官网（官方 PE/股息率），每日积累历史样本
- **分位说明**：PE分位基于本地积累样本，首期约20期、每日自动增加，样本越多越可靠；创业板红利比分位基于近3年价格，从第一天起即可用
- 本工具仅作数据监测与量化参考，**不构成投资建议**；市场有风险，投资需谨慎

## 修改信号阈值

编辑 `etf_monitor.py` 顶部 `TH` 字典中的参数即可（如 `pe_low`/`pe_high`/`rsi_low` 等），保存后重跑脚本生效。

## 故障排查

- 无更新：检查计划任务状态（任务计划程序 → ETF每日监测 → 运行状态），或看 `run_log.txt`
- 看板显示"积累中"：当日估值接口暂不可用，次日会自动重试
- 依赖问题：确保 Python 环境可 `import akshare, pandas, numpy, requests`（工具使用 `D:\APP\Python\python.exe`）
