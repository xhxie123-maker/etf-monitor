# ETF 智能监测工具（单窗口看板）

监测 **红利 515180 / 银行 516310 / 煤炭 515220** 三只 ETF，一个浏览器页面看完全部指标。

## 云端看板（手机/电脑随时看，无需开电脑）

**看板网址：https://xhxie123-maker.github.io/etf-monitor/output/etf_dashboard.html**

- 由 GitHub Actions 每个工作日 15:35（北京时间）自动更新，更新后自动发布到该网址
- 手机、轻薄本打开网址即看全部指标
- 仓库 Actions 页可手动点「Run workflow」立即更新
- 估值历史随仓库持久化（`output/valuation_history.csv`），每日自动追加官方真值

## 本地快速开始

- **自动运行**：已配置 Windows 计划任务「ETF每日监测」，每个工作日 15:30 收盘后自动更新看板
- **手动更新**：双击 `run_monitor.bat`，更新后自动打开浏览器
- **查看看板**：打开 `output\etf_dashboard.html`（双击即可，无需联网，ECharts 为本地文件）

## 看板内容

1. **宏观环境**：利率环境（中国10Y国债收益率 + 较20日前变化bp）、政策风向（LPR 1Y/5Y + 手动维护条目）、市场情绪（两市成交额 + 较20日均量比，放量/缩量提示），每日自动更新
2. **创业板红利比**：创业板指(399006) ÷ 中证红利(000922)，近3年历史分位 + 风格轮动建议（<0.35 成长占优 / >0.60 红利占优）
3. **单只ETF卡片**：最新价、涨跌幅、PE + 三档滚动分位（近1年/近3年/近5年）、分位样本数与起止日期、股息率、RSI、MA20/MA60、偏离20日线、做T支撑/压力位
4. **买卖信号**：综合评分制（估值+RSI+布林+均线+偏离），输出 强烈分批买入 / 逢低分批买入 / 观望持有 / 逢高减仓（估值项采用**近3年分位**；RSI 为 Wilder 平滑口径，超卖/超买阈值 rsi_low=35 / rsi_high=70，信号与做T建议共用同一阈值）
5. **定投建议**：按PE分位分档（双倍 / 正常 / 减半 / 暂停）
6. **价格走势图**：近250日收盘 + MA20/MA60 + 布林带
7. **估值分位走势图**：PE分位·近3年滚动窗口（750交易日）逐点折线
8. **长期操作纪律**：基准仓位、再平衡规则、风险提示

## 数据源与说明

- **行情（自动回退链）**：东方财富（前复权，本机优先）→ 腾讯（当日、海外可访问）→ 新浪（T-1 兜底）。GitHub Actions 海外环境访问东财会被拒绝/限流，自动切腾讯，数据仍为当日
- **估值**：中证指数官网（官方 PE/股息率）优先；海外不可达时自动沿用仓库积累库（看板估值徽章变黄提示），次日重试
- **积累库**：`output/valuation_history.csv` 由本地与云端各自积累并自动提交，两处独立增长、不互相同步；存放中证官网官方估值真值，每日 +1 期
- **PE 分位（日频估算口径）**：以官方最新 PE 为锚，用**指数日线点位**（中证红利 000922 / 中证银行 399986 / 中证煤炭 000820，真实点位、无复权问题）按比例回推近 5 年日频 PE 序列（假设 EPS 近似恒定）；近约 20 个交易日以积累库官方真值覆盖；末端强制对齐官方最新 PE。分位按滚动窗口计算并标注样本数（交易日）与起止日期：近1年=250期 / 近3年=750期 / 近5年=1250期，主信号取近3年档
- **宏观指标**：利率=中国10Y国债收益率（英为财情 `bond_zh_us_rate`，较20日前变化bp，<2.0% 宽松 / >2.8% 偏紧，可调）；政策=LPR（央行 `macro_china_lpr`）＋ `MACRO_POLICY` 手动维护条目（每周更新）；情绪=两市成交额（腾讯指数日线 上证000001+深证399001 的 amount 字段求和，口径为千元，较20日均量 >1.2 放量 / <0.8 缩量，可调）。任一数据源失败仅该格显示 --，不影响主流程
- 本工具仅作数据监测与量化参考，**不构成投资建议**；市场有风险，投资需谨慎

## 修改信号阈值

编辑 `etf_monitor.py` 顶部 `TH` / `MACRO_TH` 字典中的参数即可（如 `pe_low`/`pe_high`/`rsi_low`/`y10_low` 等），保存后重跑脚本生效。政策风向条目在 `MACRO_POLICY` 中维护。

## 故障排查

- 无更新：检查计划任务状态（任务计划程序 → ETF每日监测 → 运行状态），或看 `run_log.txt`
- 看板显示"积累中"：当日估值接口暂不可用，次日会自动重试
- 依赖问题：确保 Python 环境可 `import akshare, pandas, numpy, requests`（工具使用 `D:\APP\Python\python.exe`）
